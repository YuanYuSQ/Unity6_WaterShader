## 准备与导入

验证环境为 **Unity 6000.4.3f1 + URP 17.4 + Windows D3D12 + Forward+**。当前代码使用硬件曲面细分与 RenderGraph，不是 Built-in / HDRP Shader；移动端、WebGL、XR 等没有兼容性保证。

完整导入需要以下文件；不要只复制主 Shader：


| 部分       | 必需文件                                                                         |
| ---------- | -------------------------------------------------------------------------------- |
| 水面       | `ToonWater_Interaction_Reviewed.shader`、同目录 `ToonWaterReviewed.hlsl`         |
| 背景与反射 | `WaterReviewColorFeature.cs`                                                     |
| 涟漪       | `WaterRippleSimulation.cs`、`WaterRippleInteractor.cs`、`WaterRippleWave.shader` |
| 中文面板   | `Editor/ToonWaterReviewedGUI.cs`、`Editor/WaterReviewDebugDrawer.cs`             |

Editor 脚本必须放在名为 `Editor` 的目录下。水面 Shader 与 HLSL 保持相邻。没有预制材质和演示场景时，按下一节手动搭建。

## 快速搭建水面

### 1. 配置渲染输入

1. 确认当前质量等级使用正确的 URP Asset，Renderer 使用 Forward+ 与 RenderGraph。
2. 在 URP Asset 开启 **Depth Texture**、**Opaque Texture**，确认相机没有禁用它们；不要假设 Shader 会自动生成深度。
3. 在相机实际使用的 Renderer Data 添加 **Water Review Color Feature**。
4. 初次使用：`Reflection Downsample=2`、`Refraction Downsample=1`、`Pre Water Transparent Layers=Nothing`。创建水材质后将其填入 `Water Material`；多份水材质需求不一致时留空。
5. 如果捕获不工作，确认相机不是 Preview / Reflection、没有输出到自定义 RenderTexture，且 Renderer 有中间颜色目标；必要时在 Renderer 检查 Intermediate Texture 配置。当前 Feature 会跳过直接 BackBuffer 路径。

### 2. 创建材质与网格

1. 创建材质，选择 **Custom → ToonWater_Interaction_Reviewed**。
2. 将材质赋给水平 Plane 或具有连续 UV 的水面网格。以 1 Unity 单位约 1 米调参。
3. 指定法线、焦散、泡沫噪声；没有某种素材时可以关闭对应效果，三张图并非缺一就无法渲染。
4. 将“调试与系统数据 → 旧吃水线”关闭。Shader 为兼容保留的默认值是开启，独立包没有旧高度捕获链路。
5. 确认整体可见度 1、Debug 为 None。初次先用细分“低”，需要倒影时将总反射强度从默认 0 调高，并打开 SSR；选择 SSR“中”作为起点。

材质新建默认值与开发场景已调好的数值不同。例如总反射强度、PBR 高光强度默认均为 0，不表示模块故障。

### 3. 抗锯齿与第一轮观察

可从 URP Asset **4× MSAA**、相机允许 MSAA、相机后处理开启、**SMAA High** 开始验证。它们有 GPU 成本，按目标平台取舍。观察近景、远景、斜视角、移动镜头，以及物体露出水面的轮廓；静止截图通过不代表动态闪烁消失。

> **完成标志：** 水底可见、法线流动、深浅水色变化正常；开总反射后能看到探针 / 屏幕反射；Console 没有编译或资源错误。先确认这些，再接交互。

## 贴图准备

当前随包贴图来自开发工程水材质的实际引用，保留原始内容、GUID 与导入设置：

| 材质属性 | 随包文件 |
|---|---|
| `_NormalMap` | `Textures/Water_Normal.tga` |
| `_CausticsTex` | `Textures/T_Caustics06.png` |
| `_FoamNoiseTex` | `Textures/FoamNoise_Linear.png` |

法线文件仅缩短文件名；无需修改 Shader。导入已有开发工程时请复用原资源，避免复制相同 GUID。贴图具体导入建议见使用手册。


| 贴图            | 导入与内容要求                                                             | 不配置时                                 |
| --------------- | -------------------------------------------------------------------------- | ---------------------------------------- |
| `_NormalMap`    | Texture Type=Normal map，Repeat，开启 Mipmap；优先上下左右均连续的法线素材 | 使用平法线，细波纹弱或不明显             |
| `_CausticsTex`  | 可平铺的焦散图案，Repeat / Mipmap；作为强度数据使用时采用线性导入          | 默认黑，不出现焦散；可设焦散强度 0       |
| `_FoamNoiseTex` | 主要读取 R；Repeat / Mipmap，关闭 sRGB，优先无缝噪声                       | 默认白，泡沫形状单调，并影响消融和碎斑   |
| `_RippleTex`    | 模拟器自动创建的 RGFloat RT，R 高度、G 速度                                | 无模拟器时无交互；无需手填或创建 R8 图片 |

非无缝法线可暂用“贴图接缝修补宽度”0.15；增加到 0.2 左右观察过渡，最大 0.25。它改变采样，不修改原图。已经无缝的素材设为 0，减少额外采样。

## 按顺序调出效果

数值是起点，材质面板的“高级”保留细调项。完整默认值见[参数参考](parameters.md)。


| 顺序 / 面板分组   | 先调什么                                                  | 判断标准                                                 |
| ----------------- | --------------------------------------------------------- | -------------------------------------------------------- |
| 1 水色与可见度    | 浅水色、深水色、深水感度；再调染色、水底保留 / 曝光       | 深浅关系清晰，水底不过曝；整体淡出用“整体可见度”       |
| 2 几何波浪        | A 主形状、B 交错方向、C 小波；方向 / 速度 / 陡峭度 / 波长 | 先看轮廓起伏，再增加细分；固定陡峭度加长波长也会增高波浪 |
| 3 细波纹与法线    | 贴图缩放、强度、两层速度；第二层比例                      | 反射与折射细节不过碎；方形边界先查源图连续性             |
| 4 水下折射        | 折射强度，色散先 0；接触柔化约 0.08 米                    | 水底有扭曲但不大幅拉扯岸边；柔化过大会出现透明边带       |
| 5 岸边与泡沫      | 基础宽度、极限深度、消融、溶解、流速                      | 区分白沫宽度与水面缺口；浪尖阈值不要超过波高范围         |
| 6 环境反射        | 总强度 → 探针 → SSR → 粗糙度 → 亮度                   | 正视角和掠角都检查，SSR 丢失时回退平顺                   |
| 7 水底焦散        | 强度、范围、两层流速                                      | 只增强浅水细节，避免成为整片白光                         |
| 8 阳光碎斑        | 强度、密度、阈值                                          | 远处和移动镜头不过度闪烁                                 |
| 9 主光高光        | 强度、直接高光粗糙度、抗锯齿                              | 与环境倒影分别调；F0 约 0.02 作为起点                    |
| 10 透光           | 颜色、强度、集中度                                        | 逆光方向可见，不用来整体提亮水底                         |
| 11 边缘泛光       | 强度、范围、与反射分离度                                  | 避免掠角整片发白                                         |
| 12 交互涟漪       | 高度强度 1、法线增益 4、波峰亮边 0.5                      | 先确认测试圈，再按美术风格减弱                           |
| 13 调试与系统数据 | Debug、旧吃水线、运行时状态                               | 调完恢复 None；纹理与范围由模拟器绑定                    |

“低 / 中 / 高”是参数组合，不代表特定硬件等级或帧率保证；打开面板不会自动改动材质。选择档位会修改对应参数，定制值会显示“自定义”。

## 让物体与水交互

### 水面端

1. 在水面或独立管理对象添加 **Water Ripple Simulation**。
2. `Water Renderer` 指向真正绘制水面的 Renderer，`Material Index` 填水材质槽下标（通常 0）。
3. `Simulation Shader` 拖入 **WaterRippleWave.shader**，Shader 名为 `Hidden/WaterReview/RippleWave`。
4. 初始可用：Resolution=512、Wave Speed=3、Damping=1.2、Edge Absorption=3、Max Height=0.35。
5. 保持水面水平、位置和范围稳定；同一个 Renderer 只允许一个模拟器。禁用旧模拟器 / 发射器，避免同时驱动同一水面。
6. 进入 Play，确认 Inspector“已就绪”。对准开阔水面，点击 **在镜头前测试涟漪 · 12 秒**。

测试按钮用固定半径 **1.8 米**、力度 **-6**，每 **1.5 秒**一圈，持续 **12 个游戏时间秒**。它不依赖 Sphere，也不读取物品半径；停止按钮会清空当前涟漪。

### 物体端

1. 给物体添加 **Water Ripple Interactor**，确认对象和组件启用。
2. 将 `Simulation` 绑定到上述模拟器，`Contact Collider` 指定物体碰撞体。
3. 初始使用半径 0.65、入水力度 1.5、尾波力度 0.5、接触容差 0.12。
4. Play 中让物体穿过水面，再贴着水面水平移动，分别观察入水圈与尾波。

Rigidbody 不必需。此组件按碰撞体包围盒与解析水面高度判断，不依赖 Trigger 回调；没有碰撞体时按物体位置与半径建立替代包围盒。物体须在水域矩形范围内；完全在水下移动不会持续发尾波。

### 手动触发接口

已有游戏逻辑中可调用以下代码，不必为每个视觉事件创建物体：

```csharp
// simulation 是已绑定、已就绪的 WaterReview20260923.WaterRippleSimulation。
bool accepted = simulation.EmitRipple(hitPoint, 0.8f, -2.0f);
// true 仅表示脉冲入队；不要逐帧打印 accepted。
```

接口使用世界 XZ，Y 不参与注入；调用者自行决定接触条件。力度单位米/秒，负值先向下压。队列最多 32，未就绪 / 越界 / 无效参数 / 队列满会返回 false。

## 涟漪大小与触发规则

### “大小”对应不同控制


| 想改变的效果         | 应调整的地方                | 说明                                           |
| -------------------- | --------------------------- | ---------------------------------------------- |
| 刚入水时更大一圈     | 物体 Interactor → 涟漪半径 | 控制初始扰动范围，单位米                       |
| 水面压得更深 / 更强  | Interactor → 入水力度      | 改注入速度，过大受最大波高限幅                 |
| 后续扩散更快         | Simulation → 传播速度      | 受稳定性限制，实际速度可能低于输入             |
| 传播更远、持续更久   | Simulation → 减小衰减      | 没有固定“最终半径”；速度、衰减、边界共同决定 |
| 让同样波纹更显眼     | 材质 → 法线扰动 / 波峰亮边 | 主要改外观，不增加模拟器初始半径               |
| 放大整个水面涟漪位移 | 材质 → 涟漪高度强度        | 也放大法线坡度，不用于单独区分不同物体         |

有效半径至少为 **2 个网格间距**，最多较短水域边长的 **1/4**。约 65.22 米、512² 时，一格约 0.127 米，最小有效半径约 0.255 米；小于此值继续调小不会缩小。如果需要更细的小涟漪，增分辨率或缩小水域，并观察 GPU 成本。

### 何时会发散


| 情况                             | 当前行为                                             |
| -------------------------------- | ---------------------------------------------------- |
| 进入接触带、中心穿越、离开接触带 | 各自可能触发一次；共享最短间隔                       |
| 一次完整下沉                     | 可能触发多个脉冲，不保证严格一圈                     |
| 贴水水平移动                     | 同时满足速度、时间和距离条件才有尾波                 |
| 停在水面                         | 不按固定频率持续发散；大波浪改变接触状态时仍可能触发 |
| 深水移动                         | 无持续尾波                                           |

默认尾波条件：速度 ≥0.2 米/秒、间隔 ≥0.1 秒、距上次发射点 ≥0.25 米。将“尾波力度”设 0 可关闭移动尾波，但接触事件仍可能多次发生。将入水力度和尾波力度都设 0 则不产生物体扰动。

目前没有“一次性 / 持续 / 扰动力阈值”的模式下拉选项，也不检测质量和冲击力。需要严格一次触发时，应由游戏逻辑管理状态并调用 `EmitRipple`。

## 透明物体与水体叠加

默认背景捕获主要面向不透明场景。确需让透明物体进入水下折射时：

1. 为这些物体创建专用 Layer，不能把水面放进去。
2. 将该 Layer 加入 Feature 的 `Pre Water Transparent Layers`。
3. 从 Renderer 常规 `Transparent Layer Mask` 排除同一 Layer，避免重复绘制。
4. 确认相机 Culling Mask 包含它。

此方法把指定层整体提前绘制；适用于确定在水面后的对象。跨水面玻璃、覆盖水面的粒子、多层交错透明仍需单独排序方案。透明物体不会因此自动进入深度或 SSR 命中。

## 调试模式

在材质“调试与系统数据”选择模式，面板会同步关键词。检查完点击“恢复正常渲染”。


| 值    | 内容               | 主要用途                             |
| ----- | ------------------ | ------------------------------------ |
| 0     | None               | 正常渲染                             |
| 1     | SSR                | 看屏幕追踪是否命中；受置信度影响     |
| 2     | Probe              | 检查探针输入                         |
| 3     | Mixed              | 检查最终反射混合                     |
| 4     | Normal             | 法线方向、接缝                       |
| 5     | Foam               | 白沫分布                             |
| 6     | Shore Gradient     | 深度梯度诊断，不代表正在驱动泡沫方向 |
| 7     | Fresnel Factor     | 反射掠角范围                         |
| 8 / 9 | Glow / Glow Factor | 泛光颜色与分布                       |
| 10    | SSR LOD            | 实际命中采样层级，需有效反射资源     |
| 11    | Ripple Height      | 灰色为零，亮为正、暗为负             |
| 12    | Ripple Normal      | XZ 涟漪梯度                          |
| 13    | SSR Confidence     | 命中可靠程度                         |
| 14    | SSR Steps          | 消耗步数占设置上限的比例             |

脚本切换示例（作用于选定水材质）：

```csharp
material.SetFloat("_DebugMode", 11);
material.SetFloat("_DebugEnabled", 1);
material.EnableKeyword("_WATER_DEBUG");
// 恢复时：模式和 DebugEnabled 设 0，再 DisableKeyword("_WATER_DEBUG")。
```

SSR 浮点开关也要与 `_WATER_SSR` 同步。构建时需保留计划使用的变体；没有打包的变体不能靠运行时关键词重新生成。

## 常见问题


| 现象                     | 优先检查                                            | 调整 / 下一步                                         |
| ------------------------ | --------------------------------------------------- | ----------------------------------------------------- |
| 材质变粉                 | Unity / URP 版本、HLSL 相邻路径、编译错误、细分支持 | 按 Console 首个错误排查；不要只拷贝主 Shader          |
| 中文面板没出现           | 两个 Editor 文件、编译状态、材质 Shader 名          | 检查 Editor 目录和命名空间；不要给旧 Shader 套新面板  |
| 水面全部消失             | 整体可见度、旧吃水线、相机深度、对象 / 材质槽       | 可见度设 1，旧吃水线关闭；再查裁剪和 bounds           |
| 没有反射                 | 总反射默认 0、SSR 关键词、Feature / 深度 / 探针     | 先看 Debug 2，再看 1 / 13；相机输出 RT 不走当前捕获   |
| 粗糙度只调了却没模糊     | 是否运行新版 Feature、是否命中 SSR                  | 旧 Opaque Texture 不能自动当作有 Mipmap；看 Debug 10  |
| 没有涟漪                 | Play、就绪状态、波纹 Shader 引用、物体启用 / 绑定   | 先用 12 秒预览，再看 Debug 11；高度场有圈则查视觉参数 |
| 涟漪数据有变化但看不清   | 原有波浪 / 法线 / 反射过强                          | 临时减弱基础细节，法线增益 4、亮边 0.5 验证后回调     |
| 改物体半径但测试圈不变   | 是否用 12 秒预览                                    | 预览固定 1.8 米；用真实物体交互看半径                 |
| 静止物体偶尔有圈         | Gerstner 改变接触状态                               | 检查接触容差和波高；不是固定频率发射                  |
| 随波纹移动的方形接缝     | 法线图四边是否连续                                  | Repeat / Mipmap 正确后，用接缝补偿或换无缝图          |
| 物体轮廓白边 / 锯齿      | 接触柔化、深度、MSAA / SMAA                         | 从 0.08 米柔化开始；过大有透明带                      |
| 远处岸线缺口明显         | 消融噪声与高频泡沫 / 高光                           | 临时将消融设 0 分辨真实缺口；降低噪声频率和高亮强度   |
| Debug 选了没变化         | 是否新版、关键词、整体可见度                        | 用面板选择；脚本同步关键词；可见度 0 会先裁剪         |
| 每隔几帧 CPU 数百 ms     | Profiler 的 CPU 层级、日志等                        | 本工程仍在更新；需在当前机器重新取样                  |
| 侧看或大浪水面突然被裁掉 | Renderer bounds 未覆盖位移                          | 当前没有自动扩界，需要项目侧正确设置网格包围盒        |

## 性能与构建检查

优先按实际瓶颈调节：细分与距离 → SSR 步数 / 精化 / 开关 → 反射降采样 → 涟漪分辨率 → 高频效果和抗锯齿。关闭 SSR 后可保留探针；Feature 绑定正确材质才便于跳过不必要的反射资源。


| 涟漪分辨率 | 两张 RGFloat 像素存储 | 取舍                                 |
| ---------- | --------------------- | ------------------------------------ |
| 256²      | 约 1 MiB              | 便宜，宽水域的小扰动更粗             |
| 512²      | 约 4 MiB              | 当前开发场景起点                     |
| 1024²     | 约 16 MiB             | 更细，但每步处理像素是 512² 的 4 倍 |

运行中改分辨率 / 绑定目标后重新启用模拟器。水域范围变化会清空旧波纹。默认每帧最多补 4 个模拟步、每队列 32 个扰动；超限计数用于诊断，不要逐帧打印。

发布前检查：

- 在干净工程导入完整文件，等待编译完成，确认没有同名类型重复。
- 目标质量等级的 URP Asset / Renderer 正确，Feature 生效，深度和颜色输入可用。
