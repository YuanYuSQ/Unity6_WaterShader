# 后续更新方向

**从水面表现，扩展到水上与水下的完整交互。**

[使用手册](usage.md) · [技术现状](technical-design.md) · [参数参考](parameters.md)

> [!NOTE]
> 以下是待推进的方向与验收目标，不是已实现功能，也不是发布日期承诺。现有代码基线为 Reviewed 2026-09-23。

## 路线概览

| 阶段 | 方向 | 核心结果 | 状态 |
|---|---|---|---|
| **01** | 吃水线 | 水面高度、相机与物体交界判断一致 | 规划中 |
| **02** | 水下效果 | 水面上下切换自然，水下深度层次清楚 | 规划中 |
| **03** | 浮力 | 物体随波起伏，并受到阻尼和水阻 | 规划中 |
| **04** | 粒子特效 | 入水、出水、尾波和气泡形成统一反馈 | 规划中 |

建议先统一水面查询和交互事件，再扩展表现。水下效果依赖稳定的吃水线；浮力和粒子可以复用水面查询与入水事件，避免各自计算不同的水面位置。

---

## 01 · 吃水线

**目标：让水与物体、镜头之间的交界稳定且连续。**

当前接触柔化已处理部分透明轮廓问题，但旧高度捕获、旧吃水线与新波浪 / 涟漪还没有统一。接触柔化不能替代完整吃水线方案。

- 统一水面高度、范围、世界坐标和法线查询，明确 Gerstner 与涟漪各自的参与方式。
- 整理旧高度捕获与裁剪链路，处理相机近裁面跨越水面的遮罩。
- 让波浪起伏时的物体交界与镜头半入水表现衔接，减少断层、误裁剪和白边。

**验收场景：** 静水与大浪；物体缓慢 / 快速穿水；相机上下移动和半入水；近景、远景与掠角。高度、遮罩与最终画面应一致。

## 02 · 水下效果

**目标：从水面看水底、进入水下、再离开水面的视觉连续。**

目前焦散、染色与折射属于水面表面的近似。现有开发工程中的旧水下链路不等于新版完整水下系统，最小发布包也没有包含它。

- 基于水内路径长度设计颜色吸收、雾化和能见距离。
- 增加可调水下色调、散射感与光照衰减，明确与水面焦散的职责。
- 处理上 / 下水切换与半屏水下遮罩，避免整屏突然切色。
- 验证水下观察水面、透明物体和后处理的顺序，提供分档质量配置。

**验收场景：** 浅水、深水、岸边、半入水与往返穿越；颜色过渡稳定，避免重复染色，后处理只覆盖实际水下区域。

## 03 · 浮力

**目标：让可交互物体漂浮、倾斜和随波运动。**

当前 `SurfaceHeight` 仅用于接触近似，未包含 GPU 涟漪，也没有向 Rigidbody 施加力。把该接口用于完整浮力前，需要明确精度、延迟和更新频率。

- 提供多点浸没采样，按位置施加浮力和力矩。
- 加入垂直阻尼、线性水阻和角阻尼，控制跳动与长时间摇摆。
- 支持体积 / 质量和采样点配置，区分漂浮、悬浮与下沉的物体。
- 评估异步高度查询或解析近似，避免逐物体、逐帧同步 GPU 读回。

**验收场景：** 球体、箱体和长条物体；不同质量；静水与波浪；多物体同场。检查稳定性、受力方向、固定物理步长与渲染帧率不一致时的表现。

## 04 · 粒子特效

**目标：让入水动作与水面涟漪共同表达力度和方向。**

当前只有水面高度、法线与亮边，没有入水水花粒子系统。粒子应由统一交互事件驱动，而不是再次独立猜测碰水。

- 入水：按接触位置、速度和物体尺度生成水花与飞溅。
- 出水：增加滴落和短时水滴，控制持续时间与数量。
- 贴水移动：增加尾迹、泡沫颗粒；水下移动可扩展气泡。
- 使用对象池、距离裁剪和数量上限，避免高频创建销毁与日志输出。
- 区分一次性事件和持续发射事件，与现有触发间隔 / 阈值设计对齐。

**验收场景：** 单次轻触、快速入水、持续移动和多个物体同时交互。水花与波圈的位置、时序和强弱对应，粒子预算受控。

## 共同基础与发布标准

| 基础工作 | 服务的方向 |
|---|---|
| 统一水面高度 / 法线 / 水域查询 | 吃水线、浮力、粒子定位 |
| 明确一次 / 持续 / 阈值交互语义 | 涟漪、浮力扰动、粒子事件 |
| 修正位移 bounds，明确多水体资源归属 | 剔除稳定性与场景扩展 |
| 持续检查透明排序、远景闪烁和深度输入 | 水面与水下视觉一致性 |
| 干净工程导入、目标 Player 与性能取样 | 每阶段发布验收 |

每完成一项，再补齐对应组件说明、参数、示例、实测截图和限制。没有完成的方向继续保留“规划中”，避免使用者把路线图当作已有能力。
